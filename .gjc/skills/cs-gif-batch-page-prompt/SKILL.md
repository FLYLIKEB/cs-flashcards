# CS GIF Batch Page Prompt

아래 템플릿을 그대로 복붙해서 쓰면 됩니다.

## Copy-paste template

```text
<대상 섹션/문서군>을 확인해서, GIF 예시가 없는 문서들에 대해 알맞는 GIF를 생성해 넣어줘.

요구사항:
- 각 문서를 먼저 읽고, 이미 GIF가 있는 문서는 건드리지 마.
- GIF가 없는 문서만 골라서 적절한 GIF를 만들어 넣어.
- **설명문보다 움직임만 보고 작동 원리가 직관적으로 이해되게** 만들어.
- 텍스트/자막은 최소화.
- 정적인 이미지 말고 실제 **looping GIF**로 생성.
- 각 GIF는 해당 문서의 핵심 동작을 가장 잘 보여줘야 해.
- 위키 문서에는 서버에 올라간 GIF URL을 연결해 넣어.
- 문서 안에는 파일 경로나 출처 같은 운영 정보는 넣지 마.
- 작업 후 어떤 문서에 어떤 GIF를 넣었는지 정리해.

품질 기준:
- 2~6초 안에 핵심 동작 한 사이클이 보여야 함
- 반복(loop) 시 어색하지 않을 것
- 모바일/위키 본문 폭에서도 식별 가능할 것
- active 요소가 색상/강조로 분명할 것
- 긴 설명 없이도 동작 원리를 이해할 수 있을 것

의도:
- 학습자가 문서를 읽다가 바로 아래 GIF만 보고도 구조와 알고리즘의 상태 변화를 이해할 수 있어야 해.
```

## Fill-in helper

- `<대상 섹션/문서군>` 자리에 예:
  - `위키의 자료구조/알고리즘 하위 문서들`
  - `네트워크 섹션의 모든 하위 문서`
  - `09-02 트리와 그래프 관련 문서들`

## Good request examples

- `위키의 자료구조/알고리즘 하위 문서들을 확인해서, GIF 예시가 없는 문서들에 대해 알맞는 GIF를 생성해 넣어줘.`
- `트리/그래프 관련 하위 문서들을 점검해서 GIF 없는 문서만 골라 직관적인 GIF를 채워줘.`

# CS GIF Prompt Pack

이 스킬은 학습용 GIF 요청 템플릿 3개를 한 번에 모아 둔 묶음입니다.

## 어떤 템플릿을 써야 하나

- **1. 단일 개념용**: 스택, 큐, DFS, 힙처럼 한 개념만 정확히 GIF로 만들고 싶을 때
- **2. 문서 일괄 점검용**: 특정 섹션 하위 문서를 훑어 GIF 없는 문서만 채우고 싶을 때
- **3. 병렬 배치용**: 문서 수가 많아서 서브에이전트 병렬 실행까지 강하게 요구하고 싶을 때

---

## 1) 단일 개념용 템플릿

```text
<개념명>을 설명하는 학습용 GIF를 만들어줘.

요구사항:
- 설명문보다 **움직임만 보고 작동 원리가 직관적으로 이해되게** 만들어.
- 텍스트/자막은 최소화.
- 한 번 보면 “아, 이렇게 동작하는구나”가 바로 와야 해.
- 정적인 인포그래픽 말고 실제 **looping GIF**로 만들어.
- 핵심 상태 변화가 분명히 보여야 해. (예: push/pop, enqueue/dequeue, 탐색 순서, split, swap, relax 등)
- 모바일/위키 본문 폭에서도 식별 가능하게 만들어.
- active 요소는 색상/강조로 분명히 보여줘.
- 결과물은 실제 `.gif` 파일로 만들고, 최종 연결은 서버 URL로 하도록 준비해.

의도:
- 시험/면접용 학습 자료라서 긴 설명보다 동작 구조를 한눈에 이해시키는 게 목적이야.
- “설명”이 아니라 “상태 변화 시각화”에 집중해.
```

예:
- `스택을 설명하는 학습용 GIF를 만들어줘.`
- `힙에서 extract-max 후 재정렬되는 과정을 설명하는 학습용 GIF를 만들어줘.`

## 2) 문서 일괄 점검용 템플릿

```text
<대상 섹션/문서군>을 확인해서, GIF 예시가 없는 문서들에 대해 알맞는 GIF를 생성해 넣어줘.

요구사항:
- 각 문서를 먼저 읽고, 이미 GIF가 있는 문서는 건드리지 마.
- GIF가 없는 문서만 골라서 적절한 GIF를 만들어 넣어.
- **설명문보다 움직임만 보고 작동 원리가 직관적으로 이해되게** 만들어.
- 텍스트/자막은 최소화.
- 정적인 이미지 말고 실제 **looping GIF**로 생성.
- 각 GIF는 해당 문서의 핵심 동작을 가장 잘 보여줘야 해.
- 위키 문서에는 서버에 올라간 GIF URL을 연결해 넣어.
- 문서 안에는 파일 경로나 출처 같은 운영 정보는 넣지 마.
- 작업 후 어떤 문서에 어떤 GIF를 넣었는지 정리해.

품질 기준:
- 2~6초 안에 핵심 동작 한 사이클이 보여야 함
- 반복(loop) 시 어색하지 않을 것
- 모바일/위키 본문 폭에서도 식별 가능할 것
- active 요소가 색상/강조로 분명할 것
- 긴 설명 없이도 동작 원리를 이해할 수 있을 것
```

예:
- `위키의 자료구조/알고리즘 하위 문서들을 확인해서, GIF 예시가 없는 문서들에 대해 알맞는 GIF를 생성해 넣어줘.`
- `트리/그래프 관련 하위 문서들을 점검해서 GIF 없는 문서만 골라 직관적인 GIF를 채워줘.`

---

## 3) 병렬 배치용 템플릿

```text
<대상 섹션/문서군>의 하위 문서들을 확인해서, GIF 예시가 없는 케이스들을 전부 찾아 알맞는 GIF를 생성해 넣어줘.

중요:
- **각 요소별로 서브에이전트를 띄워 병렬 실행해.**
- 문서별 또는 개념별로 작업을 분할해서 동시에 처리해.

요구사항:
- 각 문서를 읽고, 이미 GIF가 있는 경우는 제외.
- GIF가 없는 케이스만 골라서 적절한 GIF를 생성.
- **설명보다는 직관적인 움직임으로 어떻게 작동하는지 알 수 있게** 만들어.
- 텍스트/자막은 최소화.
- 실제 **looping GIF** 파일을 생성.
- 위키 문서에는 서버에 올라간 GIF URL을 연결.
- 문서 안에 파일 경로, 출처, 운영 메모는 넣지 마.
- 작업 후 문서별 추가 GIF 목록과 반영 결과를 정리해.

분업 기준:
- 선형 자료구조 / 트리 / 그래프 / 정렬 / 탐색 / DP처럼 문서군별로 나눠도 좋고,
- 스택 / 큐 / 연결리스트 / 힙 / DFS / BFS처럼 개념별로 나눠도 좋다.
- 핵심은 서로 독립적인 단위로 쪼개 병렬 처리하는 것.
```

예:
- `위키의 자료구조/알고리즘 내의 각 모든 하위 문서 중, gif 예시가 없는 케이스들을 전부 확인해 알맞는 gif를 생성해 넣어줘. 설명보다는 직관적인 움직임으로 어떻게 작동하는지 알 수 있게 해야해. 각 요소별로 서브에이전트 띄워 병렬실행.`
- `네트워크 하위 문서 전체를 확인해서 GIF 없는 개념들을 병렬로 나눠 생성하고 연결해줘.`

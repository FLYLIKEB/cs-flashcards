## 제출 전 확인사항

- 회사명 기재가 가능한 블라인드 채용인지 확인
- 각 프로젝트의 본인기여도를 증빙 가능한 기준으로 입력
- 장애 추적·운영 안정화 경험의 정확한 시작일·종료일 확인
- Deprecated 클래스 자동화와 기획전 노출 자동화의 정확한 시작일·종료일 확인
- 최소주문금액 프로젝트의 협업 단위가 `유관부서`인지 `팀`인지 확인
- 기술 밋업 사회 횟수는 4회와 5회로 기록이 달라 증빙 후 추가
- Slack 앱의 사내 프로젝트 귀속 여부와 정확한 활동기간 확인

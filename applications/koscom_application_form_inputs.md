### 교과목 입력 전 확인

- `전공`, `전공기초`, `교양` 등 과목유형은 학사시스템의 실제 이수구분과 일치시킨다.
- `SW·AI비즈니스응용설계`, `SW프로그램`은 강의계획서나 수강편람에서 IT 관련 학과 개설 여부를 확인한다.
- 과목명은 성적증명서의 띄어쓰기와 기호를 그대로 사용한다.
- 성적은 `B0`, `C0`처럼 숫자 0 표기를 그대로 사용한다.
- 현재 수강 중인 과목은 넣지 않는다.

## 2. 성적증명서 업로드

- 발급받은 성적증명서 PDF를 그대로 업로드한다.
- 지원서에 입력하지 않은 과목도 성적증명서에서 확인되므로 과목 누락을 성적 은폐처럼 설명하지 않는다.
- 면접에서 학점 질문을 받으면 학점 자체를 변명하기보다 이후 직업교육과 실무에서 학습 방식을 바꾼 증거를 제시한다.

권장 답변 방향:

> 전공 이수 과정에서 성적 관리가 부족했던 점은 사실입니다. 이후 백엔드 직업교육에서는 Java·Spring 기반 미션, 테스트와 코드리뷰를 반복했고, 실무에서는 성능지표와 로그로 원인을 검증하는 방식으로 학습 습관을 바꿨습니다. 그 결과 TPS 1,000 환경에서 API 응답시간을 909ms에서 18ms로 줄이고, 대규모 시스템과 데이터를 운영 중단 없이 이관하는 경험으로 역량을 증명했습니다.

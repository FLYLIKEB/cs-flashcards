# 유클 CTO 커피챗 · 한 질문씩

프로그램 홈의 **유클 CTO 커피챗 · 200문항** 메뉴에서 `/ucle-interview/`로 이동합니다. 기존 앱과 같은 인증을 적용합니다.

- 원본 200문항·9개 분야 유지. 한 줄 핵심 → 말하기용 답변 → 쉬운 풀이 순서로 펼칩니다.
- 짧은 문단과 굵은 주요 키워드, 선택 가능한 핵심 15문항, 분야·검색·다시 볼 질문 필터를 제공합니다.
- 5문항을 직접 연습 표시하면 쉬기 안내가 나옵니다. 시간 제한과 자동 완료 처리는 없습니다.
- 현재 위치·답변 단계·필터·연습 표시·쉬는 상태는 `ucle-interview-study-v1`에 저장됩니다. 다른 기기와 동기화되지 않습니다.
- JavaScript가 없으면 모든 질문과 답변을 읽을 수 있습니다.
- `source.md`는 사용자 제공 2026-11-18 자료입니다. 회사 현황과 전형 상태는 현재 사실로 재검증한 것이 아닙니다. 기존 소재은행과 충돌하거나 경험이 불확실한 부분은 답변에서 구분합니다.

답변 원본은 `answers-001-070.json`, `answers-071-140.json`, `answers-141-200.json`입니다. 수정 후 저장소 루트에서 `python3 scripts/build_ucle_interview.py`를 실행하면 페이지와 다운로드용 `answers.md`가 갱신됩니다. 생성기는 원문 번호·누락·중복·강조·답변 문단 수를 검사합니다.

`deploy_lightsail_flashcards.sh`는 필요한 정적 파일만 패키징합니다. SQLite 파일과 기존 학습 기록은 이 기능에서 수정하지 않습니다.

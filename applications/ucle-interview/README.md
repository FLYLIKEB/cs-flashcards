# 유클 CTO 커피챗 · 한 질문씩

프로그램 홈의 **유클 CTO 커피챗 · 200문항** 메뉴에서 `/ucle-interview/index.html`로 이동합니다. 기존 앱과 같은 인증을 적용합니다.

- 원본 200문항·9개 분야 유지. 한 줄 핵심 → 말하기용 답변 → 쉬운 풀이 순서로 펼칩니다.
- 짧은 문단과 굵은 주요 키워드, 선택 가능한 핵심 15문항, 분야·검색·다시 볼 질문 필터를 제공합니다.
- 5문항을 직접 연습 표시하면 쉬기 안내가 나옵니다. 시간 제한과 자동 완료 처리는 없습니다.
- 현재 위치·답변 단계·필터·연습 표시·쉬는 상태는 `ucle-interview-study-v1`에 저장됩니다. 다른 기기와 동기화되지 않습니다.
- JavaScript가 없으면 모든 질문과 답변을 읽을 수 있습니다.
- `source.md`는 사용자 제공 2026-11-18 자료입니다. 회사 현황과 전형 상태는 현재 사실로 재검증한 것이 아닙니다. 기존 소재은행과 충돌하거나 경험이 불확실한 부분은 답변에서 구분합니다.

답변 원본은 `answers-001-070.json`, `answers-071-140.json`, `answers-141-200.json`입니다. 수정 후 저장소 루트에서 `python3 scripts/build_ucle_interview.py`를 실행하면 페이지와 다운로드용 `answers.md`가 갱신됩니다. 생성기는 원문 번호·누락·중복·강조·답변 문단 수를 검사합니다.

`deploy_lightsail_flashcards.sh`는 필요한 정적 파일만 패키징합니다. SQLite 파일과 기존 학습 기록은 이 기능에서 수정하지 않습니다.

## 음성으로 한 질문씩 자동재생

**음성으로 시작하기**를 누르면 현재 질문 → 한 줄 핵심 → 말하기용 답변 → 쉬운 풀이를 읽어 줍니다. 다음 질문 자동재생은 기본 켜짐이며, 현재 선택한 분야·핵심 문항·다시 볼 질문·검색 범위 안에서 다음 문항으로 이어집니다. 마지막 문항에서 멈춥니다.

- 200개의 한국어 MP3를 포함합니다. 음성 재생 시 실제 구간 시간에 맞춰 답변 단계가 펼쳐집니다.
- 재생·일시정지·처음부터·탐색·0.8~1.5배속을 지원합니다. 자동재생을 끄면 현재 문항까지만 듣습니다.
- 재생 중 이전·다음·문항 선택으로 이동하면 새 문항도 바로 재생됩니다. 일시정지 중 이동하면 멈춘 상태를 유지합니다. 우선순위·분야·검색 범위를 바꾸거나 쉬기를 누르면 음성이 멈춥니다. 다시 시작하려면 재생을 누르세요.
- 새로고침해도 학습 위치와 배속·자동재생 설정은 유지되지만, 음성은 자동으로 시작하지 않습니다. 연습 완료 표시는 직접 해야 합니다.
- 휴대폰은 첫 재생 버튼 조작이 필요하며, 잠금 화면·백그라운드에서의 연속 재생은 기기와 브라우저에 따라 제한될 수 있습니다.
- 음원 생성: `python3 scripts/render_ucle_audio.py`. 검증: `python3 scripts/render_ucle_audio.py --verify-only`. macOS Yuna와 FFmpeg로 실제 음원·구간 시간을 만들며, 생성 후 듣는 데에는 별도 음성 서비스가 필요 없습니다.

## 우선순위와 분야별 보기

화면 상단에서 **1순위 · 먼저 준비 / 2순위 · 기본 다지기 / 3순위 · 심화**와 9개 분야를 조합해 선택합니다. 200문항을 66/89/45개로 나눴으며 모든 분야에 세 단계가 있습니다. 출제 확률이 아니라 커피챗 준비 순서입니다. 우선순위와 분야 설정은 기존 연습 표시·복습 기록과 함께 저장됩니다.

분류 원본은 `priorities.json`이며 `python3 scripts/build_ucle_interview.py`로 적용합니다. 질문·답변·음원은 이 분류로 바뀌지 않습니다.

별도 [기술스택 키워드 기초](stack-basics.html)에서 Next.js 등의 쉬운 뜻과 예시를 볼 수 있습니다.

# 박지우 이력서

## 경력 요약

Java·Spring 기반 커머스 백엔드 개발자 박지우입니다. 우아한형제들에서 B마트 API 개발·성능 개선·도메인 이관을 담당했습니다.
TPS 1,000 환경에서 배너 API 응답시간을 909ms→18ms로 약 98% 단축했으며, 92개 API 이관과 100만 건 규모의 데이터 처리 경험이 있습니다.
개인 프로젝트에서는 주문·결제와 실시간 웹 서비스를 구현하고, 콘텐츠 기획·제작과 사용자 유입까지 경험했습니다.

## 핵심 역량

- 성능 개선: JPA 조회·캐싱 최적화, N+1 개선, 부하 테스트와 모니터링을 통한 전후 검증
- 데이터 안정성: 주문 트랜잭션, 재고 잠금, 결제 멱등 처리, 실시간 상태 저장·복원
- 개발·운영 자동화: Spring Batch, SQL 진입점 로깅, 사내 워크플로우 및 배포 자동화
- 주요 기술: Java, Spring Boot, JPA, MySQL, TypeScript, NestJS, Next.js

## 실무 경력 | 우아한형제들 · 백엔드 개발자

2023.01~2024.11 · 정규직

- B마트 전시 API 최적화: TPS 1,000에서 배너 API 909ms→18ms, 추천 카탈로그 API TPS 23% 증가·응답시간 20% 단축.
- 장애 진단 개선: MDC 기반 SQL 진입점 로깅을 구현해 원인 파악 시간 25분→9분 단축.
- 도메인 이관: 신규 가게홈 서버 구축 및 전시 API 92개 마이그레이션.
- 대용량 처리·자동화: 100만 건 대상 할인 알림 배치 구현, 20여 개 팀·100여 개 워크플로우를 위한 Slack 통합 솔루션 설계·구현.
- 문제 해결 과정을 사내 기술 블로그와 서버개발그룹 밋업에서 공유.

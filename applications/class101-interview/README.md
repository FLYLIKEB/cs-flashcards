# 클래스101 면접 연습 사이트

모바일 접속: <https://cs.chamung.com/interview/>

기존 CS 학습 사이트와 같은 계정으로 로그인합니다. 휴대폰에서 **질문 듣기** 또는 **답변 듣기**를 누르면 저장된 한국어 MP3가 재생됩니다. **연속 듣기 · 음성 설정**을 펼치면 현재 문항부터 연속 듣기와 배속을 선택할 수 있습니다. 첫 재생은 직접 버튼을 눌러 시작합니다. 연습 기록과 밑줄은 기기·브라우저별로 저장됩니다.

서버 배포는 `scripts/deploy_lightsail_flashcards.sh`가 면접 페이지·글꼴·음원 200개를 함께 포함합니다. `/interview/`와 음원에는 기존 인증이 적용되며, 오디오 구간 요청(HTTP Range)을 지원합니다.

`questions.md`에 질문 원문 100개, `answers.md`에 질문별 답변 초안을 분야별로 정리했습니다. `index.html`을 브라우저로 직접 열거나, 저장소 루트에서 다음 명령으로 로컬 서버를 실행합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory applications/class101-interview
```

주소: <http://127.0.0.1:8765>

- 기본 화면은 한 번에 한 문항만 보여 줍니다. 질문을 읽고 직접 답한 뒤 **답변 보기**로 비교하고 **다음 문항**으로 이동합니다.
- **문항 고르기**를 펼치면 분야별 이동, 100문항 선택, 전체 보기, 모두 펼치기·접기, Markdown 다운로드를 사용할 수 있습니다.
- 답변 편집 원본은 `answers-01-30.md`, `answers-31-60.md`, `answers-61-100.md`입니다. 수정한 뒤 `python3 scripts/build_class101_interview.py`로 `index.html`과 통합 `answers.md`를 다시 생성합니다. 생성기는 10개 분야, 분야별 10문항, 1~100번 순서와 답변 누락·중복을 검증합니다.
- 각 문항은 **핵심 키워드 3~5개 + 면접에서 말하기 쉬운 구어체 답변**으로 구성합니다. 필요한 기술 용어는 남기고 일상적인 설명과 예시로 풀었으며, 한 문장마다 줄을 나눕니다. 경험 질문은 이력서의 성과를, 설계 질문은 선택할 기술과 이유를 중심으로 답합니다.
- 기술 개념을 복습할 공식 문서는 [참고 자료](references.md)에 모았습니다.
- 별도 설치나 외부 네트워크 요청 없이 동작합니다.
- 글꼴은 [Pretendard v1.3.9](https://github.com/orioncactus/pretendard/tree/v1.3.9)의 가변 웹폰트를 로컬에서 불러옵니다. 폰트 파일과 SIL Open Font License는 `fonts/`에 포함했습니다.

## 집중해서 연습하기

- **이 문항 연습했어요**는 직접 표시하는 연습 기록입니다. 재생이나 다음 문항 이동만으로 자동 완료 처리하지 않으며, 다시 눌러 취소할 수 있습니다.
- 마지막 문항, 답변 펼침 여부, 연습 표시와 보기 방식은 현재 브라우저에 저장됩니다. 새로고침 후에도 같은 문항으로 돌아오며 음성은 자동 재생하지 않습니다.
- **잠깐 쉬기**는 음성을 멈추고 현재 문항을 남겨 둡니다. 쉬는 중 새로고침해도 복귀 버튼을 눌러야 연습 화면으로 돌아옵니다. 음성 재생 위치 자체는 새로고침 후 복원하지 않습니다.
- **연속 듣기 · 음성 설정**에서 현재 문항부터 듣기, 전체 연속 듣기, 배속, 이전/다음 음성과 정지를 사용할 수 있습니다. 연속 재생 시 현재 문항이 따라 바뀌며, 답변 음성이 시작될 때 답변이 펼쳐집니다.
- 직접 다른 문항으로 이동하면 이전 음성을 정지합니다. 시간 제한과 자동 진행 압박 없이 원하는 속도로 연습할 수 있습니다.
- 학습 상태는 `class101-interview-study-v1`, 개인 밑줄은 기존의 별도 키에 저장합니다. 콘텐츠·음원·밑줄 데이터는 이 화면 변경으로 수정하지 않습니다.

## 키워드와 밑줄

- 핵심 키워드 목록과 답변 본문에 등장하는 해당 키워드를 굵게 표시합니다. Markdown 다운로드에도 반영됩니다.
- 질문 또는 답변의 한 문단 안에서 글자를 선택한 다음 **밑줄 긋기**를 누릅니다. 같은 방식으로 선택 후 **밑줄 지우기**를 누르면 선택한 부분의 밑줄을 지웁니다.
- 밑줄은 현재 브라우저에 자동 저장되며 새로고침 후에도 유지됩니다. 다른 기기나 Markdown 다운로드에는 포함되지 않습니다. 브라우저 데이터를 삭제하면 밑줄도 삭제됩니다.
- 답변 내용이 수정되면 해당 문단의 이전 밑줄은 적용하지 않습니다.

## 음성 듣기

- 질문을 펼친 뒤 **질문 듣기**, **답변 듣기**로 각각 재생합니다.
- **여기부터 연속 듣기**는 해당 문항부터 100번까지, **전체 연속 듣기**는 1번부터 재생합니다.
- 연속 모드는 **질문 → 답변**, **질문만**, **답변만** 중 선택할 수 있습니다. 모드 변경 후 연속 듣기를 시작하면 적용됩니다.
- 일시정지·이어서 듣기·정지·이전/다음 음성, 0.8~1.5배속과 오디오 탐색을 지원합니다.
- 음성은 키워드 목록을 제외하고 실제 말할 답변 본문을 낭독합니다.
- 재생 중인 문장을 연두색 배경과 밑줄로 표시하고 문장 진행에 따라 배경이 채워집니다. 일시정지·배속·음성 탐색에도 현재 위치를 반영합니다. 직접 저장한 밑줄은 그대로 유지합니다.
- **재생 위치 따라가기**를 끄면 재생 중에도 화면이 자동 이동하지 않습니다. 기기의 동작 줄이기 설정을 사용하면 부드러운 이동과 애니메이션을 줄입니다.
- 문장별 음성을 합쳐 만든 실제 구간 시간을 사용합니다. 강조는 문장 단위이며 단어별 발음 위치를 나타내지는 않습니다.
- 한국어 음원은 `audio/`의 MP3 200개입니다. 페이지를 열거나 새로고침해도 자동 재생하지 않습니다.

질문·답변을 수정하면 페이지와 음원을 모두 다시 만듭니다. 음원 생성에는 macOS의 Yuna 음성과 FFmpeg가 필요하며, 생성된 파일을 듣는 데는 필요하지 않습니다.

```sh
python3 scripts/render_class101_audio.py
python3 scripts/build_class101_interview.py
```

휴대폰의 화면 잠금·백그라운드 전환 중 연속 재생은 브라우저와 운영체제의 미디어 정책에 따라 제한될 수 있습니다.


## 경력·직무 기반 화이트보드 8문제

`whiteboard.html`은 [박지우 이력서](../park_jiwoo_resume.md)와 [클래스101 PP 팀 공고](../class101_backend_job_posting.md)를 기준으로 선정한 예상 연습문제입니다. 실제 기출이나 출제 확률 순위가 아닙니다. 기존 100개 질문은 별도 생성 자료이므로 선정 사실의 독립 근거로 쓰지 않습니다.

| 순서 | 문제 / 알고리즘 | 이력서 연결 | PP 팀 공고 연결 |

| 2 | 내부 거래와 PG 거래 대사 / 해시 조인 | 커머스 백엔드·대용량 데이터 처리 | 결제부터 정산까지 자금 흐름의 정확성 |

대사·정산은 지원 직무에 맞춘 연습 주제이며 이력서에 없는 실무 수행 경험으로 서술하지 않습니다. 실제 회사의 쿠폰 배분·이용권·요청 제한 정책은 알 수 없으므로 문제 안에서 가정합니다. 단일 프로세스 알고리즘과 운영 환경의 트랜잭션·원자성·재시도 보장은 구분합니다.
